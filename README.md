This project analyzes user engagement patterns across different internship domains using Machine Learning and Data Analytics techniques. The goal is to understand how users interact with internship opportunities, identify the most engaging domains, and uncover trends that can help organizations improve internship programs and candidate engagement.
Objectives :
1.Analyze user engagement across various internship domains.
2.Identify the most popular internship categories.
3.Discover patterns and trends in user interactions.
4.Build machine learning models to predict engagement levels.
Technologies Used :
1.Python
2.Pandas
3.NumPy
4.Matplotlib
5.Scikit-learn
6.Jupyter Notebook
